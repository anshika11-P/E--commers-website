# Velora – E-commerce Website
click here to visit the website
https://anshika11-p.github.io/E--commers-website/

Velora is a modern and responsive e-commerce website built using HTML, CSS, and JavaScript. It features a clean white, cream, and beige design.

## Features

- Responsive homepage
- Product listing
- Product search
- Category filters
- Add to cart
- Quantity management
- Wishlist
- Cart total calculation
- Newsletter form
- Local storage support
- Mobile navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images

## Project Structure

Velora/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone this repository.
2. Open the Velora folder.
3. Open index.html in your browser.
